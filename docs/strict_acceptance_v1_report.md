## 结论与限制

当前版本适合继续做受控Demo和联调，但未达到“严格下游可用率90%”目标，也未通过危险误放行为0的硬门槛。主要缺口是目的地/角色绑定、组合任务、否定障碍、口语以及上下文指代。

本仓库的 `codearts_adapter/` 与 `tracecoder_adapter/` 当前只有占位文件，因此本报告验证的是意图IR/BT到内部执行前门禁的可调度性，不代表已经经过真实策略生成器、运动规划器或机器人固件执行。最终固件可执行率必须在统一仓库完成下游适配、仿真和真机回传后另行统计。

600条中有382种不同自然语言指令，其余为相同表达在不同感知对象、ID或场景上的独立实例。它能够评测实体绑定和场景一致性，但仍不能等同于600种完全不同的语言表达。
